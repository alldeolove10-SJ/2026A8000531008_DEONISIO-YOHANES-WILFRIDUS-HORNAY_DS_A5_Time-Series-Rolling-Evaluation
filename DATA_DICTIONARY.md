# Data Dictionary

## Dataset Information

- **Assignment:** DS-A5 | Time-Series Rolling Evaluation Lab
- **Dataset name:** Synthetic Daily Demand Dataset
- **Source:** Generated by the project code
- **Purpose:** Evaluate forecasting models using rolling-origin evaluation and examine temporal drift.
- **Limitations:** Synthetic data may not completely represent real-world demand.

## Variables

| Variable | Type | Description |
|---|---|---|
| date | Date | Date of each observation |
| demand | Numeric | Synthetic daily demand |
| shift_period | Indicator, if present | Marks the deliberately introduced shift period |
